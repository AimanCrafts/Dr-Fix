# Dr-Fix

> Smart Home Service Management Platform

Dr-Fix is a modern web application that connects customers with trusted home service professionals such as electricians, plumbers, cleaners, carpenters, AC technicians, and more.

This project is being developed as part of:

- CSE-3100 – Web Application Development with DevOps
- CSE-2200 – Software Development IV
